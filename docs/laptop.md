# RTX 5090 Laptop 可能沒有 16-pin 電壓欄位

### 筆電 GPU 的電力供應方式與桌面版不同：
  - 桌面版：透過 16-pin (12VHPWR) 連接器，電壓應為 ~12V
  - 筆電版：透過主機板內部電源供應，通常沒有暴露此電壓欄位

### 如果 Log 顯示進入「估算模式」，這表示 NVML 沒有提供 16-pin 電壓資料，這對筆電 GPU 是預期行為。

  可能的替代方案：
  - 監控 GPU Core 電壓（如果有暴露）
  - 純粹監控溫度（對筆電更有意義）
